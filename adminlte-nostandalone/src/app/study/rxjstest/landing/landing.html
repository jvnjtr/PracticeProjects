RXJS

Reactive Extensions for JavaScript (RxJS) is a library for reactive programming using Observables, to make it easier to compose asynchronous or callback-based code.

RxJS provides a powerful way to handle asynchronous data streams and events in JavaScript applications. It allows you to work with data that changes over time, such as user input, HTTP requests, or WebSocket connections, in a more declarative and composable manner.

RxJS is commonly used in Angular applications for handling asynchronous operations, such as HTTP requests, user interactions, and real-time data streams. It provides a wide range of operators that allow you to manipulate and transform data streams in various ways, making it easier to manage complex asynchronous logic.

  • Switch map
  • Merge Map
  • Combine Latest
  • Subject
  • Behavior Subject
